# Minuto de Oro — Demo Würth Argentina

Demo interactiva del módulo **Minuto de Oro** para la aplicación Warrior (Connect Würth).
Simula el flujo completo que realizará el vendedor en la tablet antes y durante una visita comercial.

## Ver la demo

Abrir `index.html` en un navegador o publicar en GitHub Pages.

## Flujo demostrado

1. **Dashboard del cliente** — punto de entrada con acciones disponibles.
2. **Minuto de Oro** — preparación de estrategia con cuatro secciones:
   - Reposición (historial de compra 12 meses)
   - Dinero Nuevo (magníficos e imprescindibles nunca comprados)
   - Lanzamientos y Promociones
   - Selección propia
3. **Carrito / Visita** — gestión del pedido con indicadores de semáforo.
4. **Cierre** — venta concretada o cierre por motivos parametrizables.

## Funcionalidades interactivas

- Selección/deselección de productos con mínimos obligatorios por sección (4/3/3).
- Botón "Iniciar Visita" habilitado solo al cumplir los tres mínimos.
- Precarrito con barra amarilla vertical que identifica productos del Minuto de Oro.
- Edición de cantidades, eliminación con motivo obligatorio parametrizable.
- Indicadores en tiempo real: líneas, dinero nuevo, magníficos e imprescindibles.
- Cierre con venta o cierre sin venta (no atendió, cerrado, otro, cargar horarios).

## Objetivo del proceso

Pasar de 6,4 a 8 líneas promedio por pedido, vendiendo al cliente productos que hoy compra a la competencia.

## Stack

HTML + CSS + JavaScript vanilla, sin dependencias. Colores oficiales Würth.
